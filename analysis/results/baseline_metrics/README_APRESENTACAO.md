# Diagnóstico histórico do baseline

Edição exploratória de novembro de 2025. Este arquivo substitui o antigo
roteiro de apresentação; não descreve slides atuais.

O diretório preserva figuras de distâncias, gaps, componentes de loss e o
[relatório numérico](baseline_distances_report.txt). O gerador é
`analysis/scripts/analyze_baseline_distances.py`, com entradas e caminhos
históricos a conferir no próprio script antes de qualquer regeneração.

Similaridade positiva neste objetivo refere-se às views de uma amostra;
negativos não são necessariamente de classes distintas. Gaps médios e
proporções ativas não comprovam preservação de conhecimento. Os números desta
edição não devem ser substituídos silenciosamente por runs atuais.

Veja o [contexto ANT+Gap](../../../docs/history/ant_gap_results_2025.md) e a
[documentação atual de observabilidade](../../../docs/DEBUGGING_GUIDE.md).
